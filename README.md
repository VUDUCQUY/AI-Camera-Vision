# AI-Camera-Vision
AI Camera Vision: Hệ thống tự động quét mã QR &amp; xác thực PalletID trong Logistics. Sử dụng pipeline AI (YOLO + CNN) thay thế quy trình thủ công, giải mã đồng thời nhiều mã QR với độ chính xác >99%. Giải pháp giúp giảm 80% thất thoát hàng hóa, đồng bộ dữ liệu thời gian thực với WMS và tối ưu hóa vận hành cho trung tâm phân phối.
